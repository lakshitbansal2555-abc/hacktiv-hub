# Lakshit's Cyber Lair

Build a high-tech, cybersecurity-themed personal portfolio website for Lakshit Bansal, a Cybersecurity & Automation Developer and B.Tech Computer Science (Cyber Security) student at Central University of Jammu.

Visual style: Dark "hacker terminal" aesthetic — near-black background (#0a0e0f), neon accent (matrix green #00ff9d or cyber-cyan #00e5ff), monospace font (JetBrains Mono/Fira Code) for headings and code snippets, clean sans-serif (Inter) for body copy. Include an animated typing effect in the hero ($ whoami, $ status: securing systems...), a subtle circuit-board/grid background, glowing hover borders on cards, and smooth scroll-reveal animations. Keep it fast, minimal, and professional — high-tech, not cluttered.

Sections:

Hero — Name, title "Cybersecurity & Automation Developer," terminal-style animated intro, buttons: "View Resume," "Download CV," "View Projects." Social icons: GitHub, LinkedIn, Email.

About Me — Cybersecurity-focused CS student with hands-on experience across defensive security, threat analysis, and Python automation, built through multiple internships and an open-source contribution to a production FastAPI backend. Actively competing in CTFs and hackathons.

Skills — Categorized chip grid: Languages (Python, Java, C, C++), Frameworks (FastAPI, Flask), Databases (SQLAlchemy, MySQL, Firebase), Cybersecurity (Networking, Digital Forensics, Threat Analysis), Data Science (Pandas, Matplotlib), Tools (Git, Linux, Telegram API, Gmail API).

Open Source — Feature the IntelliView Orchestrator FastAPI contribution (dependency-injection refactor, unit tests, PR merged) as a highlighted case-study card.

Projects — Card grid pulling from real repos: Student Help Portal (Flask/MySQL academic resource manager), CampusCare (campus issue tracker), CampusConnect (community platform), Election Guide (JavaScript civic-info tool), E-commerce Backend (Python), Telegram Automation Bot, Gmail Automation Tool, GuardianPulse AI (security-alert translator concept). Each card: title, short description, tech tags, GitHub link.

Security Labs / CTF — Terminal-log-styled section showcasing CTF rankings (Top 4-5 university CTF, Top 9-10 individually among 70-80 participants) and custom CTF tooling scripts.

Experience — Timeline of internships (Cybersecurity, Data Science ×2, Java Development, ongoing Tech & Project internships) with dates and one-line impact each.

Contact — Glowing CTA cards for GitHub, LinkedIn, Email, and Resume download.

Footer — "Designed & Built by Lakshit Bansal — Cybersecurity • Automation • Security Research."

Fully responsive, accessible contrast on dark theme, React + Tailwind CSS, smooth fade/slide scroll animations.
